LayerPeel Studio

Run from a GitHub checkout
  npm ci
  npm run build
  python3 start.py

Open http://127.0.0.1:8046/ in Chrome. The build downloads public model
files and verifies their SHA-256 hashes. Photos are processed on your
device. A built checkout can be served locally without internet access.

Publish with GitHub Pages
  In Settings > Pages, choose GitHub Actions as the source.
  In Actions, open Deploy LayerPeel Studio and run the workflow on main.
  Later changes to main trigger the same workflow.

Use the editor
  Open a photo, then choose Separate layers. Layer Peel compares the original
  with color-tinted masks and shows transparent cutouts in Exploded Layers.
  Use each eye button to hide or show a layer. Select a tile, then use Selected
  PNG or Download ZIP in Export. The quick Edge refine slider feathers the
  preview. Restore and Erase edit the mask used for source PNGs.

  Portrait masks cover visible hair, face, body skin, clothing and accessories
  that the model identifies. Small details such as jewelry may need refinement.
  X-Ray styles visible pixels. The NSFW switch controls the on-device import
  filter and is on by default.

  Complete a piece offers labeled AI estimates for eligible object layers after
  separation on photos without detected people. Source PNGs stay separate.
  On a hosted copy, Enable offline caches the app and models for later visits.
